01REVIEWnovelm2_backtester\backtester.py:36-38
prev_pos = np.concatenate([[0.0], pos[:-1]])   # position a la barre precedente (0 avant l'ouverture)

QuestionThe fee for a position change at bar t is computed using P[t] (line 38: `fees_bar = config.BASIS_POINT * np.abs(dpos) * P`). If the strategy signal is generated on bar t's close and the trade is executed at bar t+1's open (or close), then multiplying by P[t] is an approximation but not a look-ahead issue per se. However, if pos[t] already incorporates bar t's close price to decide the trade, and the fee is also charged at P[t], this is self-consistent. The concern is whether `strategy.compute_positions` uses bar t's close to set pos[t], meaning the position change dpos[t] = pos[t] - pos[t-1] is charged at P[t] — the same price used to generate the signal — which could be look-ahead if the signal requires knowing the close before trading at that close.

Fact to verifyVerify whether strategy.compute_positions() returns a position that is meant to be decided at bar-close t and executed at bar-open t+1, or decided and executed at bar-close t; the fee calculation charges fees on position changes at bar t using P[t] (the same bar's close price), which is consistent only if execution happens at that close.

Suggested fixIf strategy.compute_positions() generates signals using bar t's close and trades are executed at bar t+1's open, shift the fee price vector: use P[1:] for position changes on bars 1..n-1 and P[0] for the initial entry, or use a separate execution-price series. If trades are executed at bar t's close (same bar as signal), the current code is correct and no change is needed.

02REVIEWnovelm2_backtester\strategy_trend.py:27-48

QuestionAt each bar t the loop computes z from prices[t] (the current bar's close), decides to enter/exit, and writes the resulting position into pos[t]. If the engine treats pos[t] as the position active during bar t — i.e., the trade is filled at the same close price used to generate the signal — the strategy is buying/selling at the exact price it just observed, which is look-ahead bias (signal and fill share the same close).
